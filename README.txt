الدخول الافتراضي:

غيّر كلمة المرور بعد أول دخول من الإعدادات.

Google Drive:
للتفعيل الكامل:
1) أنشئ مشروعاً في Google Cloud Console.
2) فعّل Google Drive API.
3) أنشئ OAuth 2.0 Client ID من نوع Web application.
4) أضف رابط الاستضافة ضمن Authorized JavaScript origins.
5) انسخ Client ID داخل إعدادات التطبيق.
يستخدم التطبيق صلاحية drive.file فقط.

PDF:
زر الطباعة يفتح مربع طباعة المتصفح، ومنه اختر Save as PDF / حفظ PDF.

التقارير:
Excel يتم تصديره كملف .xls قابل للفتح في Microsoft Excel.

ملاحظة:
الربح المحاسبي الدقيق يحتاج تكلفة البضاعة المباعة (COGS) وقيمة المخزون.
